## Проверка после изменений

- [ ] Логин начальником (`ink/ink`) успешен.
- [ ] Логин мастером (`m5/5`) успешен.
- [ ] Начальник видит список ББ.
- [ ] Мастер открывает только свою ББ.
- [ ] Рисование кистью работает.
- [ ] Текст в рамке сохраняется по клику вне рамки.
- [ ] Undo (`Ctrl+Z`) работает.
- [ ] Сохранение доски в `localStorage` работает после перезагрузки.
- [ ] Экспорт PNG работает.
- [ ] Цвет и шрифт текста после сохранения остаются корректными.
