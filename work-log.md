### Согласованный процесс изменений

- Рабочий цикл: правки в репозитории локально → `git commit` / `git push` на GitHub → на сервере в `/var/www/ink-auth` выполнять **`git pull`** (предпочтительно), затем при необходимости `npm install` в `backend` и **`systemctl restart ink-auth-api`**. Ранее для продакшена иногда использовался обход через `scp`, если на сервере не был доступен `git`; целевой вариант — подтягивать код только из Git.
