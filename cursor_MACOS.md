## 2) Шаблон как “заблокированный фон”

```js
fabric.Image.fromURL('assets/doska.png', (img) => {
  img.set({
    left: 0,
    top: 0,
    selectable: false,
    evented: false
  });
  img.scaleToWidth(canvas.width);
  canvas.add(img);
  canvas.sendToBack(img);
});
```

Зачем: мастер рисует поверх, но не ломает основу шаблона.

## 3) Добавление текста с редактированием

```js
const text = new fabric.IText('Введите текст', {
  left: 120,
  top: 100,
  fontFamily: 'Arial',
  fontSize: 24,
  fill: '#000'
});
canvas.add(text);
canvas.setActiveObject(text);
text.enterEditing();
```

Плюс: `IText` уже умеет редактирование, выделение, курсор.

```js
// Кисть

canvas.isDrawingMode = false;
const rect = new fabric.Rect({
  left: 200, top: 150,

  fill: 'transparent',
  stroke: '#0d47a1',
  strokeWidth: 3
});

```

### Как у вас устроено сейчас

- **Источник правды для кода** — то, что лежит в **Git** (GitHub), после наших коммитов и пушей.
- **Локально** у тебя на Mac должно совпадать с Git, если ты делал `git pull` и не правил файлы только руками без коммита.

Сервер мы чаще обновляли не через `git pull` (там не было `git` в PATH), а через **`scp`** — то есть на прод грузились **те же файлы, что уже были закоммичены у тебя локально и отправлены в Git**.

### Значит ли это «всё с сервера есть в Git»?

**Не всегда однозначно:**

- Всё, что мы **меняли в этом чате**, мы как правило **коммитили и пушили** — это в Git и должно быть локально после `pull`.
- Если **кто-то правил только на сервере** (ручные правки в `/var/www/ink-auth` без коммита), то такие изменения **в Git могут не попасть**, пока их специально не снять и не закоммитить.

### Как проверить себе за 30 секунд

На Mac в папке проекта:

```bash
git status
git log -1 --oneline
```

И сравни с GitHub: последний коммит на сайте репозитория должен совпадать с `git log -1`.

**Итог:** всё, что мы выкладывали через коммиты и пуш, — **и в Git, и локально (после pull)**. Сервер после `scp` получал копию тех же артефактов. То, что делали **только на сервере без записи в Git**, в репозитории может отсутствовать — это единственный зазор.
