# Корпоративный шаблон доски ИНК

Файлы в этой папке — **эталонное содержимое доски**, утверждённое для всех мастеров. Их не удаляйте из репозитория: это резервная копия независимо от сервера и базы.

| Файл | Содержимое |
|------|------------|
| `ink-company-standard.snapshot.json` | Полный снимок Fabric (canvas), один JSON на строку |
| `ink-company-standard.thumb.txt` | Data URL миниатюры для карточки шаблона |
| `ink-company-standard.preview.txt` | Data URL превью для модального окна |

Идентификатор шаблона в приложении: **`board-ink-company-standard`**  
Отображаемое имя: **«Эталонная доска»**

Обновить эталон на сервере для всех ББ (после правки файлов и деплоя):

```bash
cd backend && DATABASE_URL="postgresql://…" node scripts/seed-company-template.mjs
```

По умолчанию обрабатываются ББ **1…30** (переменная окружения `MAX_BB`).
