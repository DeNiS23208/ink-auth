## Шаг 4.2.1 — `p` -> `pointer`

### Где
В функциях:
- `startDraw`
- `moveDraw`
- `endDraw`

### Как сделать
1. В `startDraw` найди строку:
```js
const p = canvasPoint(evt);
```
замени на:
```js
const pointer = canvasPoint(evt);
```

2. Ниже в этой же функции замени:
- `p.x` -> `pointer.x`
- `p.y` -> `pointer.y`

3. То же самое в `moveDraw`:
- `const p = ...` -> `const pointer = ...`
- все `p.x`, `p.y` заменить.

4. То же в `endDraw` (где временная точка в конце рисования).

### Важно
- Меняй **только внутри этих функций**.
- Не трогай другие переменные с похожими буквами.

## Шаг 4.2.2 — `b` -> `swatchButton`

### Где
Функция `renderPalette()`.

### Как сделать
Найди:
```js
const b = document.createElement("button");
```
замени на:
```js
const swatchButton = document.createElement("button");
```

И в этом же блоке замени:
- `b.type` -> `swatchButton.type`
- `b.className` -> `swatchButton.className`
- `b.style...` -> `swatchButton.style...`
- `b.addEventListener...` -> `swatchButton.addEventListener...`
- `paintPalette.appendChild(b)` -> `paintPalette.appendChild(swatchButton)`
